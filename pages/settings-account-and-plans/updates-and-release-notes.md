Updates keep OmniForge current with fixes, reliability improvements, and new capabilities.

## Check your version

1. Open **Application Settings**.
2. Find the Updates section.
3. Review the version number.
4. Check for updates when needed.

## Read release notes

Release notes explain what changed. Read them when you notice a new behavior or want to understand recent improvements.

## If an update is interrupted

Restart OmniForge and check again. If the app still cannot update, export support logs and contact support with your version number.
