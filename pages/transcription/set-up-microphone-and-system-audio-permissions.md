OmniForge needs audio permissions before it can record. The exact prompts depend on your operating system.

## Before a real meeting

Run a short test recording. This avoids discovering permission problems during a call.

## Allow permissions

1. Open **Transcription**.
2. Start a short recording.
3. Approve microphone or system audio prompts.
4. Stop the recording.
5. Confirm transcript text appears.

If permission is denied, open your system privacy settings and allow OmniForge.

## Audio sources

OmniForge captures both microphone and system audio automatically. Make sure both permissions are granted so nothing is missed.

If capture fails, restart OmniForge after changing system permissions.
