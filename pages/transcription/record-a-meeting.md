Recordings create transcripts that can later become searchable knowledge.

## Start recording

1. Open **Transcription** (or use the menu bar / system tray on supported platforms).
2. Check that the correct workspace is active.
3. Select **Record** (or the equivalent tray/menu action).
4. Keep OmniForge open while recording.

The top navigation (and menu bar icon on macOS) will show recording status while a session is active.

## Stop recording

1. Return to OmniForge (or use the menu bar / system tray).
2. Select **Stop** (or the tray/menu equivalent).
3. Wait for final processing.
4. Rename the session if needed.

Do not close the app immediately after stopping. Let OmniForge finish saving and processing the session.

## After the meeting

OmniForge finishes the transcript and optionally generates an AI summary (if auto-process enabled in recording settings). Review the completed session on the Transcription page and use the Teach AI action to manually index the AI-generated summary into the knowledge base.
