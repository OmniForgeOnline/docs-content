OmniForge supports common document, table, transcript, and audio formats.

## Documents

Supported document formats include:

- PDF
- DOCX
- PPTX
- TXT and TEXT
- Markdown, MD, MDX
- XML

## Tables and spreadsheets

Supported table formats include:

- CSV
- TSV
- XLS
- XLSM
- XLSX

## Audio

Supported audio formats include:

- AAC, AIF, AIFF, AMR, CAF
- FLAC, M4A, MP3
- OGG, OPUS, WAV, WEBM, WMA

Code file ingestion is not currently supported.
