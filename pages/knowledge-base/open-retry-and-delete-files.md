Use the Knowledge page to manage files in the active workspace.

## Open a file

1. Open **Knowledge**.
2. Find the file.
3. Use the file action to open it.

OmniForge opens the best available source location. If the file came from OmniForge Drop, the app may open the copied file in the drop folder.

## Retry a failed file

1. Find the failed file.
2. Check that the file type is supported.
3. Use **Retry** from the file action.
4. Wait for processing to finish.

If retry keeps failing, remove the file and try a clean copy.

## Delete files

Deleting a file removes it from the workspace. If the file came from OmniForge Drop, the copied file in the drop folder is also removed.

Before bulk deletion, confirm the selected files are only the ones you want to remove.
