Answer quality depends on the question, the workspace content, and whether the relevant sources are indexed.

## Make the question easier to answer

Use:

- One task per question.
- Plain names for people, files, or projects.
- A clear output format when needed.
- Follow-up questions instead of one very long prompt.

Example:

> List the three biggest risks mentioned in the contract.

## Improve the workspace

If the Assistant cannot find something:

1. Confirm the file is in the current workspace.
2. Confirm indexing is complete.
3. Add missing notes or transcripts.
4. Remove unrelated files from the workspace if they confuse the answer.
