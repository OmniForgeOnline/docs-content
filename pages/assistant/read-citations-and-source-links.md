Citations show where an answer came from. They are the fastest way to decide whether you can trust a response.

## Open a citation

1. Ask a question in the Assistant.
2. Find the cited source in the answer.
3. Open the source link.
4. Compare the answer with the original evidence.

![OmniForge Assistant answer with citations and source links visible below the response.](/images/screenshots/assistant-answer-with-citations.webp)

If the answer matters, always check the source.

## What citations can show

A citation may point to a document, transcript, or other indexed source. The available detail depends on the source type and how the file was processed.

## When citations are weak

If citations are missing or not useful:

- Ask a narrower question.
- Mention the file or topic by name.
- Confirm the source is indexed.
- Add the missing source to the workspace.

Do not treat an uncited answer as final for sensitive work.
