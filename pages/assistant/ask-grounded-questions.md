Grounded questions are questions that can be answered from the files and transcripts in your workspace.

## Write questions with context

Good:

> What renewal dates appear in the Client A documents?

Too broad:

> Tell me everything important.

The Assistant can do broad summaries, but focused questions are easier to verify.

## Ask one thing at a time

If you need a detailed answer, split the work:

1. Ask for a summary.
2. Ask for dates, names, or decisions.
3. Ask for risks or missing information.
4. Ask for citations for the important claims.

This keeps the answer readable and makes follow-up easier.

## Use the active workspace

The Assistant answers from the selected workspace context. If a file is missing from the answer, confirm it exists in the current workspace and has finished indexing.
