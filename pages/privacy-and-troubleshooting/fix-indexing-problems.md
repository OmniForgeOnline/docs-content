If a file does not become searchable, check the file, the workspace, and the local services.

## Quick checks

1. Confirm the file type is supported.
2. Confirm the file opens outside OmniForge.
3. Confirm the active workspace is correct.
4. Keep OmniForge open until services finish starting.
5. Retry the file from the Knowledge page.

## Stuck processing

Large files and large batches can take longer. If processing never finishes, restart OmniForge and check the Knowledge page again.

## Failed files

Failed files may be corrupted, password-protected, unsupported, or temporarily blocked by a local service issue.

If retry fails, remove the file, make a fresh copy, and add it again.
