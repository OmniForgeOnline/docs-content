The Assistant depends on local services and indexed workspace content. If it is not ready, the composer may show a setup or failure message.

## Assistant is still setting up

Keep OmniForge open. Local services can need time after launch, updates, or first install.

If setup takes unusually long:

1. Restart OmniForge.
2. Confirm your computer has enough free memory and disk space.
3. Open Knowledge and check whether files can load.
4. Try the Assistant again.

## Assistant cannot answer a file question

Check that the file is in the active workspace and has finished indexing. Then ask a narrower question with the topic or file name included.

## Still blocked

Export support logs from Application Settings and share them with support.
